# Contributing

Thank you for your interest in Shimeji Nook, created by naph_.

## Report an issue

Include the operating system, application version, reproduction steps, expected result and actual result. For multiple-monitor issues, include each monitor's display scaling. Share only relevant log excerpts and remove personal information before attaching them.

## Make a change

1. Fork the repository and create a branch for the change.
2. Read README.md and build on the platform you are changing. Windows requires the .NET 10 SDK; macOS requires Xcode.
3. Test the visible character and menus. Close older application instances before launching a new build.
4. Preserve both models, their artwork and dialogue, character size and menu layout.
5. Open a pull request explaining the problem, resulting behavior, validation and any checks that were not performed.

Do not commit executables, SDKs, runtimes or build outputs. Distribute compiled applications through GitHub Releases or workflow artifacts.

The project uses the [MIT License](LICENSE). Preserve applicable licenses and credits. Write Markdown documentation in English; the main README may also include Thai.
